# Implementation Plan: 004-progress

**Branch**: `004-progress-tracking` | **Date**: 2026-04-23 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/004-progress/spec.md`

## Summary

Implement the `ProgressModule` for the VideosYT NestJS backend, plus a YouTube video player page on the frontend. The module tracks each user's watch position per video (never decrementing), marks videos complete at ≥80%, and computes track completion percentage on-the-fly. Three REST endpoints: report progress (POST), get own track progress (GET), get any user's track progress (admin GET).

## Key Implementation Notes

### Prisma Schema Addition
```prisma
model VideoProgress {
  id             String   @id @default(uuid())
  watchedSeconds Int      @default(0)
  totalSeconds   Int
  percentage     Float    @default(0)
  completed      Boolean  @default(false)
  lastWatchedAt  DateTime @default(now())
  createdAt      DateTime @default(now())
  updatedAt      DateTime @updatedAt
  userId         String
  user           User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  videoId        String
  video          Video    @relation(fields: [videoId], references: [id], onDelete: Cascade)

  @@unique([userId, videoId])
  @@map("video_progress")
}
```
Also add `progress VideoProgress[]` to `User` and `Video` models.

### Named Constant
```typescript

export const WATCH_COMPLETE_THRESHOLD = 80;
```

### Progress Report Logic (service)
```typescript
const newPercentage = Math.min(100, (dto.watchedSeconds / dto.totalSeconds) * 100);
const existing = await this.prisma.videoProgress.findUnique({
  where: { userId_videoId: { userId, videoId: dto.videoId } }
});
const maxPercentage = Math.max(existing?.percentage ?? 0, newPercentage);
const completed = existing?.completed || maxPercentage >= WATCH_COMPLETE_THRESHOLD;
await this.prisma.videoProgress.upsert({
  where: { userId_videoId: { userId, videoId: dto.videoId } },
  create: { userId, videoId: dto.videoId, watchedSeconds: dto.watchedSeconds,
             totalSeconds: dto.totalSeconds, percentage: maxPercentage, completed,
             lastWatchedAt: new Date() },
  update: { watchedSeconds: Math.max(existing?.watchedSeconds ?? 0, dto.watchedSeconds),
            totalSeconds: dto.totalSeconds, percentage: maxPercentage, completed,
            lastWatchedAt: new Date() },
});
```

### Track Progress Computation
```typescript
const activeVideos = await this.prisma.video.findMany({
  where: { trackId, isActive: true }, orderBy: { order: 'asc' }
});
const progressRecords = await this.prisma.videoProgress.findMany({
  where: { userId, videoId: { in: activeVideos.map(v => v.id) } }
});
const progressMap = new Map(progressRecords.map(p => [p.videoId, p]));
const completedCount = progressRecords.filter(p => p.completed).length;
const totalActive = activeVideos.length;
const overallPercentage = totalActive === 0 ? 0 : Math.round((completedCount / totalActive) * 100);
```

### Frontend — setInterval Pattern
```typescript
useEffect(() => {
  if (!isPlaying) return;
  const id = setInterval(reportProgress, 30_000);
  return () => clearInterval(id);
}, [isPlaying]);
```
Progress is reported silently — errors do not interrupt playback.
